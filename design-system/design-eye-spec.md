# Hop design eye

Evaluate rendered pages at measured desktop, 390px, 320px and tablet widths. Record actual widths; an API request alone is not evidence. Use real page pixels, synthetic data and complete flows. No production leads or signing.

1. Center: is a personal, candid guide to a DFW move present in both voice and behavior?
2. Hierarchy: can the visitor identify one useful next action, with appropriate alternatives?
3. Transmission: does the page consume shared components/tokens, with its own job-specific layout?
4. Truth: does the surface promise only actual capability? Are stock/location/availability/estimate claims qualified nearby?
5. States: check default, selection, field validation/focus, storage/image failure, processing, empty and completion where applicable.
6. Responsive: no horizontal document overflow; no lost action or clipped labels; phone layouts adapt ordering and reading measure.
7. Accessibility: explicit labels, focus, text feedback, adequate target size, reduced motion. Measure solid color pairs; do not call that full WCAG certification.
8. Craft: original artwork intact, no ornamental gradients or repeated template cards, no output that could introduce any agent.

Gate outcome: pass / needs refinement / external dependency. Save screenshot, viewport, route, observed behavior and limitations. Existing legal/guide facts still require broker review; this visual evaluation never certifies legal accuracy.
