## Design Context

### Users
Hop's September 30 transcripts describe DFW buyers, sellers, renters, investors and people relocating to Dallas. First-touch users need useful information before a lead form. Buyers need preferences → a shortlist conversation → lender readiness → an owned next step. Renters need the property's actual application path. Open-house visitors need a fast phone/tablet sign-in with a clear purpose; agents need dependable capture and follow-up.

### Brand Personality
Working direction: clear, neighbourly, assured. This derives from the creator's stated need for trust, useful education and practical help before requesting information. Supplied white icon and wordmark are approved identity anchors. No invented credentials, approvals, event dates or live-data claims.

### Aesthetic Direction — earlier working proposal, now under review
Architectural lettering and a familiar roof mark on a charcoal field; bright, lightly tinted surfaces for reading and daytime phone/tablet use. Restrained editorial headings paired with legible form text. Avoid repetitive cards, decorative gradients, false precision, generic luxury theatre and separate visual identities for connected tasks. Existing colors/layouts are not constraints under the user's latest instruction.

### Design Principles
1. Meaning precedes expression: show the user's next action before decoration.
2. Identity lives in behaviour: useful choices, clear estimates and honest handoffs carry the brand.
3. Reveal dependencies progressively: explain confirmations where the user needs them.
4. Transmission over performance: shared tokens, accessible labels, 48px task controls and preserved source identity.
5. Calm is controlled energy: purposeful spacing, visible focus and reduced motion; no ornamental animation.

Applied sources: September 30 Hop transcripts; supplied icon/wordmark; October 1 handoff (architecture claims pending source reconciliation); user's latest redesign instruction; Facework's meaning, transmission and behavioural-coherence principles. This is implementation context, not a claim that a full Facework eight-phase assessment is complete.
